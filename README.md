# AI Assistant with Flask

An interactive, web-based AI Assistant built with **Python**, **Flask**, and the **OpenAI SDK**. It provides a clean, lightweight chat interface that processes user prompts and returns real-time, context-aware responses powered by OpenAI models.

## Features

- **Real-Time Conversational AI:** Handles user queries and generates dynamic responses via the OpenAI API.
- **Lightweight Flask Backend:** Fast, modular routing in Python for handling frontend requests and API calls.
- **Secure Credential Management:** Uses environment variables (`.env`) to keep API keys out of source control.
- **Easy to Extend:** Structured to easily add chat history, custom system prompts, or file/document support.

## Tech Stack

- **Backend:** Python, Flask
- **AI Integration:** OpenAI Python SDK
- **Frontend:** HTML5, CSS3, JavaScript
- **Environment Management:** `python-dotenv`
